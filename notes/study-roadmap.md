# Study roadmap

This is a flexible learning plan, not a list of guaranteed interview questions. The [Java DSA Masterclass](https://www.udemy.com/course/java-data-structures-and-algorithms-masterclass/) and [Master the Coding Interview](https://www.udemy.com/course/master-the-coding-interview-data-structures-algorithms/) are learning references; use original notes and credit individual exercises.

## Suggested order

1. Java collections and [Big O](big-o.md); arrays, strings, hashing, two pointers, sliding windows and prefix sums.
2. Linked lists (including singly, doubly and circular), stacks, queues, recursion and binary search.
3. Trees, BSTs, heaps, tries, sorting and intervals; practice DFS and BFS.
4. Graph representations, traversal, topological sort, shortest paths and union-find.
5. Backtracking, greedy algorithms, dynamic programming, bit manipulation and the named array patterns in [algorithms and patterns](algorithms-and-patterns.md).
6. Revisit weak areas with mixed timed practice, then consider advanced structures and algorithms where relevant.

For every topic: explain the idea, implement a small example, analyze complexity, solve varied exercises, test edge cases, and revisit mistakes. Track what you have actually completed; a topic listed here is not automatically complete. In each problem README record the source, its official or self-assessed difficulty, approach, complexity and meaningful cases. Avoid presenting a self-assessment as an official rating.

Use the [detailed topic guides](README.md#detailed-topic-guides) alongside this order. The guides contain small illustrative Java snippets and practice prompts; these are learning material, not a claim that every exercise has a standalone implementation.

## Amazon preparation

[Amazon's software development preparation guidance](https://amazon.jobs/content/en-gb/how-we-hire/interview-prep/software-development-topics) lists coding, data structures, algorithms and other fundamentals, and advises checking likely topics with your recruiting contact. Practice explaining tradeoffs aloud, writing working Java without heavy IDE assistance, and checking edge cases. Requirements vary by role and level; confirm the current process with the recruiter.

Prepare behavioral examples using Amazon's [Leadership Principles](https://www.amazon.jobs/content/en/our-workplace/leadership-principles): describe the situation, your actions, results and lessons, with metrics where available. Depending on the role, also prepare object-oriented design, databases, operating systems, networking and system design. See Amazon's [interview preparation](https://amazon.jobs/content/en-gb/how-we-hire/interview-prep/software-development-topics) for role-specific guidance; don't assume every role has the same rounds.
