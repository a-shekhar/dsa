# Arrays

Arrays give O(1) indexed access; middle insertion and deletion generally require O(n) shifts. Dynamic arrays offer amortized O(1) append. Study fixed versus dynamic arrays, resizing, multidimensional arrays, bounds and Java `ArrayList`.

Practice implementing traversal and insertion/deletion; compare with [array problems](../../problems/arrays/README.md). No implementation is recorded here yet. See the [data structures reference](../../notes/data-structures.md) and [complexity guide](../../notes/big-o.md).
