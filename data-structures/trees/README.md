# Trees

Study binary trees, binary search trees, balanced trees, heaps and tries. Practice recursive and iterative traversals, height and level order. BST operations take O(h) for height h; a skewed tree can have h = n. A heap efficiently exposes its minimum or maximum, but its iteration is not sorted.
