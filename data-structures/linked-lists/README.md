# Linked lists

Study singly, doubly and circular linked lists; identify head, tail and pointer invariants. Given a node and appropriate references, local insertion can be O(1), but search and access by position are O(n). In a circular list, stop traversal explicitly when returning to the start.

Practice empty and one-node cases, insertion, deletion and reversal. No implementation is recorded here yet. See [linked-list problems](../../problems/linked-lists/README.md) and the [reference](../../notes/data-structures.md).

Read the [detailed linked-list, stack and queue guide](../../notes/topics/linked-lists-stacks-queues.md) for a reversal dry run and practice.
