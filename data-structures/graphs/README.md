# Graphs

Study directed and undirected graphs, weighted edges, adjacency lists and matrices. Adjacency lists occupy O(V + E) space; matrices occupy O(V²). Define whether self-loops, parallel edges and disconnected vertices are allowed.

No implementation is recorded here yet. Practice traversal and graph representation; see [graph problems](../../problems/graphs/README.md) and [graph patterns](../../notes/algorithms-and-patterns.md).
